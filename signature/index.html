Add it to Outlook

  1. Click Copy signature above.
  2. In Outlook, open Settings (gear) → Accounts → Signatures.
  3. Click + New signature, name it "Capstone", and paste (Ctrl+V).
  4. Under Select default signatures, choose it for new messages and replies. Save.
  1. Click Copy signature above.
  2. In Outlook, go to File → Options → Mail → Signatures…
  3. Click New, name it "Capstone", and paste into the edit box (Ctrl+V).
  4. Set it as default for New messages and Replies/forwards. Click OK.
  1. Click Copy signature above.
